Who are we?

We are an engineering project club!
We help UW students build the engineering skills they are passionate about with hands-on learning in a relaxed environment.

Current Projects

Stirling Engine

An engine-powered car project: refine a Stirling engine in quarter one while taking a relevant course, then assemble the car in quarters two and three.

Robotic Arm

A robotic arm project using the SO101 from Lee Robot, combining embedded systems, 3D modeling, and machine learning.

AI Embedded HIL

An AI Embedded Hardware-in-the-Loop platform where distributed AI agents autonomously write bare-metal embedded C and verify it on physical hardware. Execution data helps agents diagnose timing mismatches, fix software panics, and refactor code until all validation criteria are met.
